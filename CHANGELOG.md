# CHANGELOG — vevdokimovm.github.io

## [1.1.0] — 2026-08-28 — Десять ролей вместо четырёх; 5 мёртвых ссылок на проекты найдены и убраны (MINOR)

Владелец попросил добавить роли под остальные направления IT после того, как
ему было прямо названо, что ADR-001 держал их на четырёх намеренно («роль без
опоры превращает страницу из паспорта в перечень пожеланий»). Решение и его
основания — `docs/adr_002_ten_roles.md`.

### Added
- Роли 05–10: Frontend, Продакт-менеджер, Тимлид/менеджмент, Основатель/CEO,
  UI/UX-дизайнер, Go-разработчик. Три (Frontend/Product/Manager) реально
  подкреплены — Frontend новыми React-фронтендами, Product и Manager —
  перечтением уже имеющегося опыта (FINPILOT как продукт, онбординг стажёров)
  под новым углом. Три (Go/Designer/Founder) добавлены без реальной опоры по
  прямому решению владельца — с явной оговоркой в тексте каждой, не молча.

### Fixed
- 🔴 **5 из 7 карточек проектов вели на 404** (`bron-kerbosch`,
  `health-report-generator`, `TG-bot-for-finances`, `Web-To-Do-List`,
  `Parser-hhru-vacancies` — все удалены с GitHub при более ранней чистке
  старых студенческих реп, `data/profile.json` не обновлялся вслед).
  Убраны из `projects{}` и из `projects[]` всех ролей; добавлен `algosite`
  (`algorithms-site`, живая репа) под роль Frontend.
- Служебный блок «Структура» (`STRUCTURE:AUTO`, внутренний артефакт
  `base-repo`, не для публичной витрины) убран из README.md.
- `index.html`/`README.md`/`MANIFEST.md` — упоминания «четыре роли» приведены
  к факту (десять).

### Verified
- Проверено вживую в браузере (Chrome DevTools MCP) после публикации через
  GitHub Contents API: все 10 кнопок ролей рендерятся, хеш-роутинг работает
  (`#/go/ru`), единственная 404 в консоли — `favicon.ico`, предсуществующая,
  не от этой правки.

## [0.1.0] — визитка: четыре роли, два языка, печать в резюме (MINOR)

2026-08-16

**Добавлено**

- Одностраничная визитка: шапка с контактами, липкий селектор роли,
  восемь смысловых блоков от описания до курсов.
- Четыре роли: backend-разработчик, продуктовый аналитик, DevOps,
  C++ и алгоритмы. У каждой свой заголовок, описание, четыре показателя,
  стек и подборка проектов.
- Русский и английский полностью, включая описания всех проектов.
- Состояние в адресе страницы: `#/backend/en` — рабочая ссылка,
  её можно отправить конкретному работодателю.
- Печатная таблица стилей: страница превращается в резюме под выбранную роль,
  ссылки раскрываются адресами, переключатели скрываются.
- Всё содержание вынесено в `data/profile.json` — правка текста не касается кода.
