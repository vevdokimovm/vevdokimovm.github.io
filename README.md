## Идея

Резюме под каждую роль — это обычно N разных файлов, которые разъезжаются
через месяц. Здесь наоборот: **одна страница и один файл данных**. Переключатель
роли перенастраивает заголовок, описание, показатели, стек и порядок проектов;
опыт и образование остаются общими, потому что они и есть общие.

Работодателю не нужно гадать, тот ли перед ним человек: он выбирает роль,
на которую нанимает, и видит именно её.

## Как править содержание

Всё содержание лежит в **`data/profile.json`** — код трогать не нужно. Структура:

```
person      имя, локация, контакты
passport    паспортная таблица под шапкой, отдельно ru и en
roles[]     id, code, label, headline, summary, metrics[4], stack[], projects[]
projects{}  карточка проекта по ключу; роли ссылаются на неё ключом
experience  опыт работы, общий для всех ролей
education   образование
courses     курсы и сертификаты
ui          подписи интерфейса на двух языках
```

Поля вида `{"ru": "…", "en": "…"}` подставляются по текущему языку.
Добавить роль — дописать объект в `roles`; ничего больше не нужно.

## Запуск и публикация

```bash
python3 -m http.server 8000     # локально: http://localhost:8000
```

Открывать файл двойным щелчком нельзя — браузер запретит `fetch` по `file://`,
страница честно скажет об этом и подскажет команду.

Публикация: GitHub Pages из ветки `main`, корень репозитория. Сборки нет,
зависимостей нет, всё статическое.

## Печать

Кнопка «Скачать PDF» вызывает печать страницы. Печатная таблица стилей убирает
переключатели и подвал-подсказку, ужимает сетку и раскрывает адреса ссылок —
на выходе аккуратное резюме на одну-две страницы под ту роль, что выбрана
на экране. Отдельные PDF-файлы держать не нужно: они устареют, страница — нет.

## Границы

- Здесь **нет ничего личного, кроме профессионального**: ни здоровья, ни дневника,
  ни планов. Всё это живёт в приватных репозиториях и сюда не попадает.
- Ожидания по зарплате на странице не публикуются — это предмет разговора,
  а не характеристика изделия.
- Ссылки ведут только на публичные репозитории. Приватные не упоминаются даже
  названием.
